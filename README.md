# Murari Calculation Pro

## सबसे आसान तरीका

1. इस project की सभी files GitHub repository में upload करें.
2. `Actions` tab खोलें.
3. `Build Murari Calculation Pro APK` workflow चुनें.
4. `Run workflow` दबाएँ.
5. Build पूरा होने पर workflow के नीचे **Artifacts** में `Murari-Calculation-Pro-APK` मिलेगा.
6. उसे download करके ZIP extract करें. अंदर `app-debug.apk` मिलेगा.

### APK के बारे में
यह debug APK है और testing/installation के लिए बनाया जाता है. Uptodown पर upload करने से पहले फोन पर install करके Calculator, Exchange और Unit Converter को test करें.
